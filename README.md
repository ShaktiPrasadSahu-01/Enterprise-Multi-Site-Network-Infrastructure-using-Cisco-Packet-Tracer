# Enterprise Multi-Site Network Infrastructure using Cisco Packet Tracer

## 📖 Overview

This project demonstrates the design and implementation of a secure **enterprise multi-site network** in **Cisco Packet Tracer**. The topology connects a **Head Office** with **two Branch Offices** over redundant WAN links, providing high availability, secure communication, and scalable routing.

The network is designed to simulate a real-world enterprise environment by implementing dynamic routing, VPN connectivity, VLAN segmentation, Layer 3 switching, DHCP, NAT, and disaster recovery mechanisms.

## 🚀 Features

- Enterprise three-tier LAN architecture
- Multi-site WAN connectivity
- Dual ISP redundancy at Headquarters
- Dynamic routing using OSPF (Area 100)
- GRE/IPsec VPN tunnels between HQ and Branch Offices
- Inter-VLAN Routing using Layer 3 Switches
- VLAN segmentation
- Centralized DHCP services
- Dynamic NAT
- Destination NAT (Port Forwarding)
- Disaster Recovery (DR)
- Secure communication between all sites
- High Availability WAN Design
